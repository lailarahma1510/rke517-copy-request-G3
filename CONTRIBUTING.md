# Our team rules

1. Every change starts as an issue. The issue says who does it, who reviews it, and when it is done ("Done when").
2. One issue = one branch = one pull request. Branch names: `issue-<number>-<short-name>`, e.g. `issue-2-phone-status`.
3. Nobody commits to `main` directly (the only exception is the first "Initial commit").
4. All changes are made on our own computers and committed with GitHub Desktop or an AI agent. We do **not** use "Add file → Upload files" or the pencil button on github.com.
5. Every commit message starts with the issue number and says why.
6. Every pull request gets a **written review** from another member before it is merged. "OK" or "LGTM" alone is not a review.
7. The reviewer merges after approving. After every merge, everyone clicks **Fetch origin / Pull origin** on `main` before starting a new branch.
8. Fictional data only. No real patient names, NIK or medical record numbers.
9. The AI may help, but a person reviews every line it writes, and the pull request says what the AI did.
